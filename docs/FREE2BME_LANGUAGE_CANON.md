# The FREE 2B ME canon

Nine lines. Every page, talk, book, tool and post draws from these rather than inventing a new
slogan. That repetition is what makes the language travel; a fresh phrase per page is what stops it.

| role | line |
|---|---|
| Brand | Less fixing. More living. |
| Belief | You were never the only thing that needed to change. |
| Diagnostic question | What did &ldquo;fine&rdquo; cost? |
| Capacity principle | Capacity is conditional. |
| Responsibility question | Whose change is this? |
| Systems question | What else could change? |
| Practice principle | Support should increase authorship, not replace it. |
| Organisational line | Capacity is not a character test. |
| Practitioner line | Good intentions are not the same as good support. |

heading. No page carries more than two.

## Words that do not appear in public copy

These are how the work is built, not how it is explained. Each is banned outright unless the same
sentence translates it.

architecture &middot; shared practice &middot; operationalise &middot; domains &middot; route &middot;
conditions-and-capacity position &middot; action ownership &middot; intellectual centre &middot;
intellectual engine &middot; collapsed together &middot; locate where the work belongs &middot;
primary route &middot; audience, purpose and boundaries &middot; Misfit Matriarch

Also absent: any mention of files, proofs, source dimensions, governance decisions or implementation
constraints. A visitor never reads how the site was made.

## The sequence every page follows

recognition &rarr; relief &rarr; possibility &rarr; evidence &rarr; pathways &rarr; invitation

Not brand &rarr; services &rarr; services &rarr; founder &rarr; awards &rarr; footer. A page that
opens by describing what the organisation contains has started in the wrong place.

## Tanya is not the heroic exception

The story is that she found a question that changed the direction of her work. It is not how much
she overcame. Credentials appear after the stakes, never before, and never as the opening move.
No founder adjectives: visionary, inspirational, passionate, courageous, award-winning.

## Recognition is context, not proof

It shows the questions are reaching rooms they were not always invited into. It is never evidence
of safety, accessibility or efficacy, and it never opens a page.
